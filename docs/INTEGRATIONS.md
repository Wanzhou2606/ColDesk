# 可选集成

## 课表

杭电课表导入由用户在官方页面登录，复制自己的订阅链接，再在 ColDesk 中手动读取、预览、确认。链接可能授予课程和考试安排的读取权限，不应提交仓库、贴在 Issue 或放入截图；应用不在后台自动刷新订阅。

图片识别不自带 AI 服务：将提示词和图片交给自己选择的 AI，粘贴 JSON 后核对星期、周次、时间和地点。

## 本机助手

AI 助手页为可选的本机 OneBot 连接状态与重连入口。项目不提供 QQ 账号、机器人托管、聊天平台账号操作或远程控制权限。

个人连接文件在数据目录下的 `assistant.local.json`，不随安装包或源码分发。格式如下，各字段需自行填写：

```json
{"httpPort":3000,"token":"","reconnectTask":"YOUR_LOCAL_RECONNECT_TASK"}
```

令牌仅用于本机回环地址。`reconnectTask` 是用户自行创建的 Windows 计划任务，请了解任务内容后配置。未配置时，普通任务、日记和课表可独立使用。

`scripts/integrations/desk.js` 是供本机助手调用的 CLI，可通过 `QQ_DESK_DB` 指定数据文件、`QQ_DESK_READER` 指定安装附带的共享课表读取器。读取使用与应用相同的当前学期、校区、周次和调课逻辑。CLI 的写入能力会改变业务数据，仅应交给自己信任且获授权的本机进程。

维护者的同步脚本只在明确启用的开发机运行，更新前备份并核对已知哈希，不包含连接凭证。其他助手环境可手动接入，项目不保证所有第三方运行环境兼容。
